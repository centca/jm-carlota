# 📷 Carpeta de Imágenes

Coloca aquí las siguientes imágenes:

## Imágenes requeridas:

| Archivo | Descripción | Uso |
|---------|-------------|-----|
| `favicon.png` | Icono del sitio (32x32 o 64x64 px) | Pestaña del navegador |
| `pamplona.png` | Ilustración Pamplona-Sevilla | Timeline 2018-2020 |
| `confinamiento.png` | Ilustración del confinamiento | Timeline 2020 |
| `cadiz.png` | Ilustración de Cádiz | Timeline 2021 |
| `patagonia.png` | Ilustración Patagonia/Bariloche | Timeline 2024 |
| `malaga.png` | Ilustración de Málaga | Timeline 2025 |
| `bodega.png` | Foto de Bodegas Luis Pérez | Timeline 2026 |
| `dress_code.png` | Imagen del dress code | Sección Dress Code |

## Recomendaciones:

- **Formato**: PNG o JPG optimizado para web
- **Tamaño Timeline**: ~600x400px aproximadamente
- **Tamaño Dress Code**: ~800x600px aproximadamente
- **Peso máximo**: 500KB por imagen (para carga rápida)

## Herramientas útiles:

- [TinyPNG](https://tinypng.com/) - Comprimir imágenes
- [Squoosh](https://squoosh.app/) - Optimizar imágenes
- [Remove.bg](https://remove.bg/) - Quitar fondos
